FONTS USED ON THIS SITE
=======================

The text of this website is set in two typefaces from the TeX Gyre collection:

  TeX Gyre Pagella    (a Palatino-style serif)
    Copyright 2007--2018 for TeX Gyre extensions by B. Jackowski, J.M. Nowacki
    et al. (on behalf of TeX Users Groups). Vietnamese characters were added
    by Han The Thanh.

  TeX Gyre Heros Cn   (a condensed Helvetica-style sans serif)
    Copyright 2007--2009 for TeX Gyre extensions by B. Jackowski and
    J.M. Nowacki (on behalf of TeX Users Groups). Vietnamese characters were
    added by Han The Thanh.

Both are distributed by the TeX Users Groups under the GUST Font License
(GFL), which is an instance of the LaTeX Project Public License (LPPL),
version 1.3c. The text of the GUST Font License is below. The LPPL itself is
published at https://www.latex-project.org/lppl/ .

Source of the original fonts:
  https://www.gust.org.pl/projects/e-foundry/tex-gyre

CHANGES MADE TO THE FONTS
-------------------------

The files in this folder are modified versions of the originals:

  - cut down to the Latin characters used by this site (a subset),
  - hinting instructions removed,
  - converted from OpenType to the WOFF web format,
  - renamed inside the files to "Pagella Site" and "Heros Cn Site", as the
    GUST Font License asks of modified versions.

The original authors have not reviewed or endorsed these modified files.
